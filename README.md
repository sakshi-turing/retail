# Retail (E-commerce) Environment

## Overview

This repository contains an experimental Retail (E-commerce) environment built for the TAU Bench framework.  
The environment models a simplified retail domain including suppliers, products, orders, and shipping.

The goal of this environment is to demonstrate:
- Clear schema-driven design
- Tool-based interactions governed by policy
- Proper data flow between read and write operations
- Compliance with TAU Bench architectural standards

This environment is designed to be executed using the TAU Bench Runner, which provides the required framework at runtime.

---

## Domain Entities

The environment includes the following entities:

- Supplier
- Product
- User (Customer)
- Purchase Order
- Purchase Order Item
- Sales Order
- Sales Order Item
- Shipping

All entities strictly follow the provided schema.
